# Context and opportunity records

Employees and scoped managers or administrators can submit context for a review cycle. Each record states the type of context, a factual description, its effect on the work, and an evidence reference. Expected and actual exposure counts are optional; if used, both counts and their common unit are required. Counts must be nonnegative. Examples include machine availability, eligible cases, resources, task complexity, and disruption.

The author cannot verify their own record. An independent manager or HR/tenant administrator records a verification or rejection with a reason. Verification requires a separate evidence reference. The review is append-only. An administrative evaluation cannot be published while a context record for that employee and cycle remains unreviewed. Creating or reviewing context does not recalculate or adjust the score. Context and its review appear beside the saved evaluation trace and in the employee's data copy.

This is a documented explanation and review gate, not a validated complexity correction or causal analysis. The organization must define how context is weighed in a human decision, which evidence is acceptable, and whether an already published review needs a new appeal when later context appears. The current implementation has no automatic adjustment, uncertainty model, or crisis-specific policy.
